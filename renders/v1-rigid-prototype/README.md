# v1 prototype (superseded)

Renders of the very first design iteration (git commit `e32ad1b`): a
single rigid piece that clipped onto the screw head via a keyhole slot
and held the meter at a fixed 60° angle via its own separate foot on
the table.

This was replaced by the current two-part folding hinge design because
it didn't match the actual goal: it stuck out further than wanted and
couldn't adjust its angle. Kept here for reference only — see the
top-level README for the current design.
